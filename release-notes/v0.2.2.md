# v0.2.2

Patch release focused on browser source selection and hosted notebook behavior.

- Prefer the pinned CDN browser source before local loopback assets when `backend="auto"` falls through to the browser backend.
- Avoid probing or selecting the local asset server in hosted environments such as Colab, Kaggle, SageMaker, Binder, JupyterHub, Codespaces, and Gitpod, where the Python-side loopback URL is not reachable from the user's browser.
- Serialize the static SVG toolbar success icon with JSON escaping so embedded toolbar scripts remain valid HTML/JavaScript.
